# 🛒 Cart Management Application

## 📌 Overview

The Cart Management Application is a responsive web application built using **HTML5, CSS3, and Vanilla JavaScript**. It simulates an e-commerce shopping cart where users can add products, update quantities, remove items, and view the total cart value dynamically.

## ✨ Features

* Add products to the shopping cart
* Remove items from the cart
* Increase and decrease product quantity
* Dynamic total price calculation
* Responsive design for desktop and mobile devices
* Interactive user interface using JavaScript DOM manipulation

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JavaScript)
